# Bài học: 心配の正体

Everyday: 「日本に来て以来、毎朝お弁当を作っている」, 「あの日以来、彼とは話していない」.|自从……以来（某事之后一直持续的状态）。V-て + 以来。「その知らせを聞いて以来、仕事に集中できなくなった」。生活例：「日本に来て以来、毎朝お弁当を作っている」。|自從……以來（某事之後一直持續的狀態）。V-て + 以来。「その知らせを聞いて以来、仕事に集中できなくなった」。生活例：「日本に来て以来、毎朝お弁当を作っている」。|…한 이래로 (어떤 일 이후 계속되는 상태). Halimbawa: 「日本に来て以来、毎朝お弁当を作っている」.|…देखि (कुनै घटनापछि लगातार रहेको अवस्था)। V-て + 以来। 「その知らせを聞いて以来、仕事に集中できなくなった」। दैनिक: 「日本に来て以来、毎朝お弁当を作っている」।|Sejak … (peristiwa yang memulai keadaan berkelanjutan). Dia a dia: 「日本に来て以来、毎朝お弁当を作っている」.|… ကတည်းက (ဖြစ်ရပ်တစ်ခုနောက် ဆက်ရှိနေသော အခြေအနေ)။ V-て + 以来။ 「その知らせを聞いて以来、仕事に集中できなくなった」။ နေ့စဉ်: 「日本に来て以来、毎朝お弁当を作っている」။|ตั้งแต่ … (เหตุการณ์ที่ทำให้สภาพหนึ่งดำเนินต่อเนื่อง) V-て + 以来 「その知らせを聞いて以来、仕事に集中できなくなった」 ชีวิตประจำวัน: 「日本に来て以来、毎朝お弁当を作っている」
G たとえ〜としても #27: Cho dù … đi nữa (giả định, kết quả vẫn không đổi). たとえ + thể thường + としても. 「たとえ悪いことが起こるとしても、それは今日ではない」. Đời sống: 「たとえ雨が降るとしても、試合は行います」, 「たとえ失敗したとしても、後悔はしない」.|Even if … (hypothetical; the conclusion stands). たとえ + plain form + としても. 「たとえ悪いことが起こるとしても、それは今日ではない」. Everyday: 「たとえ雨が降るとしても、試合は行います」, 「たとえ失敗したとしても、後悔はしない」.|即使……也（假设，结论不变）。たとえ + 简体 + としても。「たとえ悪いことが起こるとしても、それは今日ではない」。生活例：「たとえ失敗したとしても、後悔はしない」。|即使……也（假設，結論不變）。たとえ + 簡體 + としても。「たとえ悪いことが起こるとしても、それは今日ではない」。生活例：「たとえ失敗したとしても、後悔はしない」。|설령 …라 해도 (가정, 결론은 변하지 않음). たとえ + 보통형 + としても. 「たとえ悪いことが起こるとしても、それは今日ではない」. 생활: 「たとえ失敗したとしても、後悔はしない」.|Kahit … (palagay; hindi nagbabago ang resulta). たとえ + plain form + としても. 「たとえ悪いことが起こるとしても、それは今日ではない」. Halimbawa: 「たとえ失敗したとしても、後悔はしない」.|… भए पनि (परिकल्पना; निष्कर्ष उही)। たとえ + सामान्य रूप + としても। 「たとえ悪いことが起こるとしても、それは今日ではない」। दैनिक: 「たとえ失敗したとしても、後悔はしない」।|Seandainya … pun (pengandaian; kesimpulan tetap). たとえ + bentuk biasa + としても. 「たとえ悪いことが起こるとしても、それは今日ではない」. Sehari-hari: 「たとえ失敗したとしても、後悔はしない」.|Mesmo que … (hipótese; a conclusão se mantém). たとえ + forma simples + としても. 「たとえ悪いことが起こるとしても、それは今日ではない」. Dia a dia: 「たとえ失敗したとしても、後悔はしない」.|… ခဲ့ရင်တောင် (ယူဆချက်၊ ရလဒ်မပြောင်း)။ たとえ + ရိုးရိုးပုံစံ + としても။ 「たとえ悪いことが起こるとしても、それは今日ではない」။ နေ့စဉ်: 「たとえ失敗したとしても、後悔はしない」။|ต่อให้ … ก็ตาม (สมมติ ผลไม่เปลี่ยน) たとえ + รูปธรรมดา + としても 「たとえ悪いことが起こるとしても、それは今日ではない」 ชีวิตประจำวัน: 「たとえ失敗したとしても、後悔はしない」
G 〜わけではない #60: Không hẳn là …, không phải là … (phủ định một phần, tránh hiểu quá mức). Thể thường + わけではない. 「セネカの言葉で、すべての悩みが消えるわけではありません」. Đời sống: 「肉が嫌いなわけではない。今日は食べたくないだけだ」, 「高ければいいというわけではない」.|It's not that … (partial denial; avoids overstatement). Plain form + わけではない. 「セネカの言葉で、すべての悩みが消えるわけではありません」. Everyday: 「肉が嫌いなわけではない。今日は食べたくないだけだ」, 「高ければいいというわけではない」.|并不是……（部分否定，避免说得太绝对）。简体 + わけではない。「セネカの言葉で、すべての悩みが消えるわけではありません」。生活例：「肉が嫌いなわけではない」。|並不是……（部分否定）。簡體 + わけではない。「セネカの言葉で、すべての悩みが消えるわけではありません」。生活例：「肉が嫌いなわけではない」。|…인 것은 아니다 (부분 부정). 보통형 + わけではない. 「セネカの言葉で、すべての悩みが消えるわけではありません」. 생활: 「肉が嫌いなわけではない」.|Hindi naman … (bahagyang pagtanggi). Plain form + わけではない. 「セネカの言葉で、すべての悩みが消えるわけではありません」. Halimbawa: 「肉が嫌いなわけではない」.|… भन्ने होइन (आंशिक अस्वीकार)। सामान्य रूप + わけではない। 「セネカの言葉で、すべての悩みが消えるわけではありません」। दैनिक: 「肉が嫌いなわけではない」।|Bukan berarti … (penyangkalan sebagian). Bentuk biasa + わけではない. 「セネカの言葉で、すべての悩みが消えるわけではありません」. Sehari-hari: 「肉が嫌いなわけではない」.|Não é que … (negação parcial). Forma simples + わけではない. 「セネカの言葉で、すべての悩みが消えるわけではありません」. Dia a dia: 「肉が嫌いなわけではない」.|… ဆိုတာ မဟုတ်ပါ (တစ်စိတ်တစ်ပိုင်း ငြင်းဆိုခြင်း)။ ရိုးရိုးပုံစံ + わけではない။ 「セネカの言葉で、すべての悩みが消えるわけではありません」။ နေ့စဉ်: 「肉が嫌いなわけではない」။|ไม่ได้หมายความว่า … (ปฏิเสธบางส่วน) รูปธรรมดา + わけではない 「セネカの言葉で、すべての悩みが消えるわけではありません」 ชีวิตประจำวัน: 「肉が嫌いなわけではない」
