# Bài học: 耳なし芳一 tập 1 (cột zh-Hant do hant.py sinh)
G なかなか〜ない #42: Mãi mà không…, khó mà… (việc không diễn ra như mong đợi dù đã chờ hoặc cố). なかなか + V thể ない. Khác: なかなか + từ khẳng định = "khá là" (なかなかおいしい). Đời sống: 「バスがなかなか来ない」, 「名前がなかなか覚えられない」, 「なかなか眠れなかった」.|Just won't…, hardly… (something doesn't happen though you wait or try). なかなか + negative verb. With a positive word it means "quite" (なかなかおいしい). Daily life: バスがなかなか来ない, 名前がなかなか覚えられない, なかなか眠れなかった.|怎么也不……、不容易……（等了或努力了仍不如愿）。なかなか＋动词否定。接肯定词时意为"相当"（なかなかおいしい）。生活：「バスがなかなか来ない」「名前がなかなか覚えられない」「なかなか眠れなかった」。|怎麼也不……、不容易……（等了或努力了仍不如願）。なかなか＋動詞否定。接肯定詞時意為"相當"（なかなかおいしい）。生活：「バスがなかなか來ない」「名前がなかなか覚えられない」「なかなか眠れなかった」。|좀처럼 …않다(기다리거나 애써도 잘 안 됨). なかなか + 부정형. 긍정과 쓰면 "꽤"(なかなかおいしい). 생활: 「バスがなかなか来ない」「名前がなかなか覚えられない」「なかなか眠れなかった」.|Ayaw…, hindi madaling… (hindi nangyayari kahit maghintay). なかなか + negatibong pandiwa. Sa positibo = "medyo" (なかなかおいしい). Halimbawa: バスがなかなか来ない, なかなか眠れなかった.|सजिलै … नहुनु (पर्खँदा/प्रयास गर्दा पनि)। なかなか + नकारात्मक क्रिया। सकारात्मकसँग = "निकै" (なかなかおいしい)। उदाहरण: バスがなかなか来ない, なかなか眠れなかった।|Tak kunjung…, sulit… (tidak terjadi meski ditunggu). なかなか + bentuk negatif. Dengan kata positif = "cukup" (なかなかおいしい). Contoh: バスがなかなか来ない, なかなか眠れなかった.|Custar a…, não conseguir… (não acontece apesar de esperar). なかなか + verbo negativo. Com palavra positiva = "bastante" (なかなかおいしい). Ex.: バスがなかなか来ない, なかなか眠れなかった.|လွယ်လွယ်နဲ့ မ… (စောင့်ပေမယ့် မဖြစ်)။ なかなか + အငြင်းပုံ။ အဟုတ်ပုံနှင့် = "တော်တော်" (なかなかおいしい)။ ဥပမာ: バスがなかなか来ない။|ไม่ยอม…เสียที (รอแล้วก็ยังไม่เกิด) なかなか + รูปปฏิเสธ ถ้าใช้กับคำบอกเล่า = "ค่อนข้าง" (なかなかおいしい) ตัวอย่าง: バスがなかなか来ない, なかなか眠れなかった
G 〜ようだ #32: Có vẻ như…, hình như… (phán đoán dựa trên những gì mình nghe, thấy, cảm nhận). Thể thường + ようだ (danh từ + の + ようだ, tính từ な + な + ようだ). Văn nói hay dùng みたいだ. Đời sống: 「隣の部屋にだれかいるようだ」, 「風邪をひいたようです」, 「雨がやんだようですね」.|It seems…, apparently… (a judgment from what you hear, see or feel). Plain form + ようだ (noun + の + ようだ, な-adj + な + ようだ). Casual speech uses みたいだ. Daily life: 隣の部屋にだれかいるようだ, 風邪をひいたようです, 雨がやんだようですね.|好像……（根据听到、看到、感觉到的作判断）。普通形＋ようだ（名词＋の＋ようだ，な形容词＋な＋ようだ）。口语常用みたいだ。生活：「隣の部屋にだれかいるようだ」「風邪をひいたようです」「雨がやんだようですね」。|好像……（根據聽到、看到、感覺到的作判斷）。普通形＋ようだ（名詞＋の＋ようだ，な形容詞＋な＋ようだ）。口語常用みたいだ。生活：「隣の部屋にだれかいるようだ」「風邪をひいたようです」「雨がやんだようですね」。|…인 것 같다(보고 듣고 느낀 것에 근거한 판단). 보통형 + ようだ(명사+の, な형용사+な). 구어는 みたいだ. 생활: 「隣の部屋にだれかいるようだ」「風邪をひいたようです」.|Tila…, mukhang… (hinuha mula sa nakikita o naririnig). Plain form + ようだ (pangngalan + の). Sa usapan: みたいだ. Halimbawa: 風邪をひいたようです, 雨がやんだようですね.|… जस्तो छ (देखेको, सुनेको आधारमा अनुमान)। साधारण रूप + ようだ (नाम + の)। बोलीचालीमा みたいだ। उदाहरण: 風邪をひいたようです।|Tampaknya…, sepertinya… (dugaan dari yang dilihat/didengar). Bentuk biasa + ようだ (nomina + の). Lisan: みたいだ. Contoh: 風邪をひいたようです, 雨がやんだようですね.|Parece que… (julgamento pelo que se vê/ouve). Forma simples + ようだ (substantivo + の). Na fala: みたいだ. Ex.: 風邪をひいたようです, 雨がやんだようですね.|… ပုံရသည် (မြင်/ကြား/ခံစားမှုမှ ခန့်မှန်း)။ ရိုးရိုးပုံ + ようだ (နာမ် + の)။ ပြောစကားတွင် みたいだ။ ဥပမာ: 風邪をひいたようです။|ดูเหมือนว่า… (ตัดสินจากสิ่งที่เห็นหรือได้ยิน) รูปธรรมดา + ようだ (คำนาม + の) ภาษาพูดใช้ みたいだ ตัวอย่าง: 風邪をひいたようです, 雨がやんだようですね
G お〜になる #23: Kính ngữ (尊敬語) nâng hành động của người trên: お + V bỏ ます + になる. 泊まる → お泊まりになる, 帰る → お帰りになる, 待つ → お待ちになる. Một số động từ có dạng riêng: 言う → おっしゃる (câu 24), いる/来る → いらっしゃる. Đời sống: 「社長はもうお帰りになりました」, 「この本をお読みになりましたか」.|Honorific (尊敬語) raising a superior's action: お + verb stem + になる. 泊まる → お泊まりになる, 帰る → お帰りになる, 待つ → お待ちになる. Some verbs have special forms: 言う → おっしゃる (sentence 24), いる/来る → いらっしゃる. Daily life: 社長はもうお帰りになりました, この本をお読みになりましたか.|尊敬语，抬高上位者的动作：お＋动词连用形＋になる。泊まる→お泊まりになる，帰る→お帰りになる。部分动词有特殊形：言う→おっしゃる（第24句），いる/来る→いらっしゃる。生活：「社長はもうお帰りになりました」「この本をお読みになりましたか」。|尊敬語，抬高上位者的動作：お＋動詞連用形＋になる。泊まる→お泊まりになる，帰る→お帰りになる。部分動詞有特殊形：言う→おっしゃる（第24句），いる/來る→いらっしゃる。生活：「社長はもうお帰りになりました」「この本をお読みになりましたか」。|존경어: お + 동사 ます형 어간 + になる. 泊まる → お泊まりになる, 帰る → お帰りになる. 특수형: 言う → おっしゃる(24번), いる/来る → いらっしゃる. 생활: 「社長はもうお帰りになりました」.|Magalang na anyo (尊敬語): お + stem + になる. 泊まる → お泊まりになる, 帰る → お帰りになる. Espesyal: 言う → おっしゃる (pangungusap 24). Halimbawa: 社長はもうお帰りになりました.|आदरार्थी (尊敬語): お + क्रिया मूल + になる। 泊まる → お泊まりになる, 帰る → お帰りになる। विशेष: 言う → おっしゃる (वाक्य २४)। उदाहरण: 社長はもうお帰りになりました।|Bentuk hormat (尊敬語): お + bentuk dasar + になる. 泊まる → お泊まりになる, 帰る → お帰りになる. Khusus: 言う → おっしゃる (kalimat 24). Contoh: 社長はもうお帰りになりました.|Honorífico (尊敬語): お + radical + になる. 泊まる → お泊まりになる, 帰る → お帰りになる. Especiais: 言う → おっしゃる (frase 24). Ex.: 社長はもうお帰りになりました.|ရိုသေစကား (尊敬語): お + ကြိယာ ပင်စည် + になる။ 泊まる → お泊まりになる။ အထူး: 言う → おっしゃる (ဝါကျ ၂၄)။ ဥပမာ: 社長はもうお帰りになりました။|คำยกย่อง (尊敬語): お + รากกริยา + になる 泊まる → お泊まりになる, 帰る → お帰りになる แบบพิเศษ: 言う → おっしゃる (ประโยค 24) ตัวอย่าง: 社長はもうお帰りになりました
