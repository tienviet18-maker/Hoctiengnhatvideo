# Bài học: 二銭銅貨 tập 1 (cột zh-Hant do hant.py sinh)
G 〜ほど #2: Đến mức…, tới độ… (mô tả mức độ bằng một ví dụ cụ thể). Thể thường + ほど + mệnh đề. Gần nghĩa với 〜くらい nhưng trang trọng hơn. Đời sống: 「泣きたいほど忙しい」, 「歩けないほど疲れた」, 「こんな言葉が出るほど貧乏だった」.|So … that…, to the point of… (shows degree through a concrete example). Plain form + ほど + clause. Close to 〜くらい but more formal. Daily life: 泣きたいほど忙しい, 歩けないほど疲れた.|到……的程度（用具体例子说明程度）。普通形＋ほど＋句子。与〜くらい相近但更正式。生活：「泣きたいほど忙しい」「歩けないほど疲れた」。|到……的程度（用具體例子說明程度）。普通形＋ほど＋句子。與〜くらい相近但更正式。生活：「泣きたいほど忙しい」「歩けないほど疲れた」。|…할 만큼, …할 정도로(구체적 예로 정도 표현). 보통형 + ほど. 〜くらい보다 격식적. 생활: 「泣きたいほど忙しい」「歩けないほど疲れた」.|Hanggang sa…, sa sobrang… (nagpapakita ng antas). Plain form + ほど. Halimbawa: 泣きたいほど忙しい, 歩けないほど疲れた.|… हुने गरी (मात्रा देखाउन)। साधारण रूप + ほど। उदाहरण: 泣きたいほど忙しい, 歩けないほど疲れた।|Sampai…, saking… (menunjukkan tingkat). Bentuk biasa + ほど. Contoh: 泣きたいほど忙しい, 歩けないほど疲れた.|A ponto de…, tanto que… (mostra grau). Forma simples + ほど. Ex.: 泣きたいほど忙しい, 歩けないほど疲れた.|… အထိ (အတိုင်းအတာ ပြ)။ ရိုးရိုးပုံ + ほど။ ဥပမာ: 泣きたいほど忙しい။|ถึงขั้นที่… (บอกระดับด้วยตัวอย่าง) รูปธรรมดา + ほど ตัวอย่าง: 泣きたいほど忙しい, 歩けないほど疲れた
G 〜ず（に） #30: Không V mà… (= 〜ないで, văn viết/trang trọng). Động từ thể ない bỏ ない + ず. する → せず. Đời sống: 「朝ご飯を食べずに出かけた」, 「何も言わずに帰った」, 「犯人はつかまらず、一週間が過ぎた」.|Without V-ing (= 〜ないで, written/formal). ない-stem + ず; する → せず. Daily life: 朝ご飯を食べずに出かけた, 何も言わずに帰った.|不V就……（＝〜ないで，书面语）。ない形去ない＋ず；する→せず。生活：「朝ご飯を食べずに出かけた」「何も言わずに帰った」。|不V就……（＝〜ないで，書面語）。ない形去ない＋ず；する→せず。生活：「朝ご飯を食べずに出かけた」「何も言わずに帰った」。|…하지 않고(= 〜ないで, 문어). ない형 + ず; する → せず. 생활: 「朝ご飯を食べずに出かけた」.|Nang hindi V (= 〜ないで, pormal). ない-stem + ず; する → せず. Halimbawa: 何も言わずに帰った.|V नगरी (= 〜ないで, लिखित)। ない मूल + ず; する → せず। उदाहरण: 何も言わずに帰った।|Tanpa V (= 〜ないで, formal). ない-stem + ず; する → せず. Contoh: 何も言わずに帰った.|Sem V (= 〜ないで, formal). Radical ない + ず; する → せず. Ex.: 何も言わずに帰った.|V မလုပ်ဘဲ (= 〜ないで)။ する → せず။ ဥပမာ: 何も言わずに帰った။|โดยไม่ V (= 〜ないで ภาษาเขียน) する → せず ตัวอย่าง: 何も言わずに帰った
G いくら〜ても #47: Dù… bao nhiêu/đến đâu cũng (kết quả không đổi). いくら + thể て + も. Đời sống: 「いくら食べても太らない」, 「いくら呼んでも返事がない」, 「いくら問いつめても、男は答えなかった」.|No matter how much… (the result doesn't change). いくら + て-form + も. Daily life: いくら食べても太らない, いくら呼んでも返事がない.|无论怎么……也（结果不变）。いくら＋て形＋も。生活：「いくら食べても太らない」「いくら呼んでも返事がない」。|無論怎麼……也（結果不變）。いくら＋て形＋も。生活：「いくら食べても太らない」「いくら呼んでも返事がない」。|아무리 …해도(결과 불변). いくら + て형 + も. 생활: 「いくら食べても太らない」.|Gaano man…, hindi pa rin. いくら + て-form + も. Halimbawa: いくら食べても太らない.|जति … पनि (नतिजा उही)। いくら + て रूप + も। उदाहरण: いくら食べても太らない।|Seberapa pun… tetap. いくら + bentuk て + も. Contoh: いくら食べても太らない.|Por mais que… (não muda). いくら + forma て + も. Ex.: いくら食べても太らない.|မည်မျှ … စေကာမူ။ いくら + て ပုံ + も။ ဥပမာ: いくら食べても太らない။|ไม่ว่าจะ…แค่ไหนก็ いくら + รูป て + も ตัวอย่าง: いくら食べても太らない
