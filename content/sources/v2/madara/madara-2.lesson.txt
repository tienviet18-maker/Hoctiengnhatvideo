G 〜てある #14: (Ai đó) đã… sẵn — trạng thái còn lại do có người CỐ Ý làm. Nối: tha động từ thể て + ある, vật làm chủ ngữ với が. So sánh: 窓が開いている (cửa đang mở, không nói ai mở) ↔ 窓が開けてある (có người đã mở sẵn, có mục đích). Đời sống: 「名前が書いてある」, 「ビールは冷やしてあります」, 「ホテルはもう予約してある」.|(Someone) has done… — a state left by someone's DELIBERATE action. Form: transitive V-te + ある, with the object as subject marked by が. Compare: 窓が開いている (the window is open) ↔ 窓が開けてある (someone opened it on purpose). Daily life: 名前が書いてある, ビールは冷やしてあります, ホテルはもう予約してある.|（有人特意）……着——有意行为留下的状态。接续：他动词て形＋ある，物作主语用が。比较：窓が開いている（窗开着）↔ 窓が開けてある（有人特意打开）。生活：「名前が書いてある」「ビールは冷やしてあります」「ホテルはもう予約してある」。|（有人特意）……著。接續：他動詞て形＋ある。比較：窓が開いている ↔ 窓が開けてある。生活：「ビールは冷やしてあります」。|(누군가 의도적으로) ~해 두었다 — 그 결과 상태. 접속: 타동사 て형+ある. 비교: 窓が開いている ↔ 窓が開けてある. 생활: 「名前が書いてある」, 「ビールは冷やしてあります」, 「ホテルはもう予約してある」.|Sinadyang ginawa (at nananatili). Anyo: transitive V-te + ある. Ihambing: 窓が開いている ↔ 窓が開けてある. Halimbawa: 名前が書いてある, ビールは冷やしてあります, ホテルはもう予約してある.|(कसैले जानाजान) गरेर राखिएको अवस्था। रूप: सकर्मक V て + ある। तुलना: 窓が開いている ↔ 窓が開けてある। उदाहरण: 「名前が書いてある」, 「ビールは冷やしてあります」।|Sudah di… (dengan sengaja, keadaannya tetap). Bentuk: V transitif -te + ある. Bandingkan: 窓が開いている ↔ 窓が開けてある. Contoh: 名前が書いてある, ビールは冷やしてあります, ホテルはもう予約してある.|Foi deixado… (de propósito; o estado permanece). Forma: V transitivo -te + ある. Compare: 窓が開いている ↔ 窓が開けてある. Exemplos: 名前が書いてある, ビールは冷やしてあります, ホテルはもう予約してある.|(တစ်စုံတစ်ယောက်က တမင်) …ထားတယ်။ ပုံစံ: သကမ္မက V て + ある။ နှိုင်းယှဉ်: 窓が開いている ↔ 窓が開けてある။ ဥပမာ: 「名前が書いてある」, 「ビールは冷やしてあります」။|(มีคนตั้งใจ) …ไว้ รูป: กริยาสกรรม て + ある เทียบ: 窓が開いている ↔ 窓が開けてある ตัวอย่าง: 「名前が書いてある」「ビールは冷やしてあります」「ホテルはもう予約してある」
G 〜にしては #22: So với… thì (lại)… — kết quả khác với điều thường mong đợi từ tiêu chuẩn đó. Nối: N / V thể thường + にしては. Thường dùng để khen bất ngờ hoặc chê nhẹ. Đời sống: 「初めてにしては上手ですね」, 「日本に十年住んでいるにしては、日本語が下手だ」, 「十二月にしては暖かい」.|For (a)…, (surprisingly)… — the result differs from what that standard would lead you to expect. Form: N / plain V + にしては. Used for surprised praise or mild criticism. Daily life: 初めてにしては上手ですね, 日本に十年住んでいるにしては、日本語が下手だ, 十二月にしては暖かい.|就……而言（却）——结果与该标准下的预期不同。接续：N／V简体＋にしては。常用于意外的夸奖或轻微的批评。生活：「初めてにしては上手ですね」「日本に十年住んでいるにしては、日本語が下手だ」「十二月にしては暖かい」。|就……而言（卻）。接續：N／V簡體＋にしては。生活：「初めてにしては上手ですね」「十二月にしては暖かい」。|~치고는 (예상과 다른 결과). 접속: N / V 보통형+にしては. 생활: 「初めてにしては上手ですね」, 「日本に十年住んでいるにしては、日本語が下手だ」, 「十二月にしては暖かい」.|Para sa…, (nakakagulat na)… Anyo: N / plain V + にしては. Halimbawa: 初めてにしては上手ですね, 十二月にしては暖かい.|…का लागि भने (अपेक्षाभन्दा फरक)। रूप: N / साधारण V + にしては। उदाहरण: 「初めてにしては上手ですね」, 「十二月にしては暖かい」।|Untuk ukuran…, (ternyata)… Bentuk: N / V biasa + にしては. Contoh: 初めてにしては上手ですね, 十二月にしては暖かい.|Para um…, até que… (contra o esperado). Forma: N / V simples + にしては. Exemplos: 初めてにしては上手ですね, 十二月にしては暖かい.|…အတွက်ဆိုရင် (မျှော်လင့်ထားတာနဲ့ မတူ)။ ပုံစံ: N / V + にしては။ ဥပမာ: 「初めてにしては上手ですね」, 「十二月にしては暖かい」။|สำหรับ…แล้ว (ผิดคาด) รูป: N / V ธรรมดา + にしては ตัวอย่าง: 「初めてにしては上手ですね」「十二月にしては暖かい」
G 〜ため(に) #49: Để…, nhằm mục đích…. Nối: V thể từ điển / N の + ため(に). Dùng khi hành động có chủ ý; với kết quả không do ý chí thì dùng 〜ように (風邪をひかないように). 〜ようにするため = để làm sao cho…. Đời sống: 「日本で働くために、日本語を勉強している」, 「健康のために、毎朝歩いています」.|In order to…, for the purpose of…. Form: dictionary V / N の + ため(に). For volitional actions; for non-volitional results use 〜ように (風邪をひかないように). 〜ようにするため = "in order to make sure that…". Daily life: 日本で働くために、日本語を勉強している, 健康のために、毎朝歩いています.|为了……。接续：V辞书形／Nの＋ため(に)。用于有意志的动作；非意志结果用〜ように（風邪をひかないように）。〜ようにするため＝为了使……。生活：「日本で働くために、日本語を勉強している」「健康のために、毎朝歩いています」。|為了……。接續：V辭書形／Nの＋ため(に)。非意志結果用〜ように。生活：「健康のために、毎朝歩いています」。|~하기 위해. 접속: V 사전형 / N の + ため(に). 비의지 결과는 〜ように. 생활: 「日本で働くために、日本語を勉強している」, 「健康のために、毎朝歩いています」.|Para…. Anyo: V diksyunaryo / N の + ため(に). Hindi sinasadyang resulta: 〜ように. Halimbawa: 日本で働くために、日本語を勉強している, 健康のために、毎朝歩いています.|…का लागि। रूप: V शब्दकोश / N の + ため(に)। उदाहरण: 「日本で働くために、日本語を勉強している」, 「健康のために、毎朝歩いています」।|Untuk…. Bentuk: V kamus / N の + ため(に). Hasil tak disengaja: 〜ように. Contoh: 日本で働くために、日本語を勉強している, 健康のために、毎朝歩いています.|Para…. Forma: V dicionário / N の + ため(に). Resultado não intencional: 〜ように. Exemplos: 日本で働くために、日本語を勉強している, 健康のために、毎朝歩いています.|…ဖို့။ ပုံစံ: V အဘိဓာန် / N の + ため(に)။ ဥပမာ: 「日本で働くために、日本語を勉強している」, 「健康のために、毎朝歩いています」။|เพื่อ… รูป: V พจนานุกรม / N の + ため(に) ตัวอย่าง: 「日本で働くために、日本語を勉強している」「健康のために、毎朝歩いています」
